# Portfólio · Deivid Santana (Next.js)

Versão em Next.js do portfólio de **Deivid Santana**, Auxiliar Técnico N1/N2 na Renea Infraestrutura e graduando em Análise e Desenvolvimento de Sistemas.

## Atualizar o conteúdo

Todo o texto (cargo, experiências, formação, certificados, métricas e links) fica em `content/profile.ts`. Os componentes em `components/portfolio/` só exibem esses dados.

## Executar

Requisito: Node.js 18 ou superior.

```bash
npm install
npm run dev           # desenvolvimento em http://localhost:3000
npm run build         # build de produção
npm run build:static  # exportação estática em out/
```

## Stack

Next.js 14, React 18, TypeScript, Tailwind CSS e next-themes.
